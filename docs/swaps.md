# Swap, drop, and pickup

- The original assignment stays until a **manager approves**.
- A staff member may have at most **3 pending** swap/drop/pickup requests.
- Staff A can cancel a pending swap before approval (regret). Staff B can decline the same way. Nothing moves on the schedule.
- If a manager edits a shift’s time, location, or skill while a swap is pending, the request is **auto-cancelled** and both parties are notified.
- If an approved swap has not happened yet and those same fields change, the swap is cancelled.
- Unclaimed **drop** requests expire **24 hours before** the shift starts; the original person stays assigned.
